# Makemore Exercises

My exercises and implementations following Andrej Karpathy's [Neural Networks: Zero to Hero](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) YouTube series.

## Contents

- `micrograd_exercises.ipynb` - Micrograd exercises (backpropagation fundamentals)
- `makemore_part2_mlp copy.ipynb` - MLP character-level language model
- `makemore_part3_bn.ipynb` - Adding batch normalization
- `build_makemore_batchnorm.ipynb` - Batch normalization deep dive
- `build_makemore_backprop_ninja.ipynb` - Manual backpropagation implementation

Based on Karpathy's [makemore](https://github.com/karpathy/makemore) repository.
